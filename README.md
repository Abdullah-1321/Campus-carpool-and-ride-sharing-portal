# Campus Carpool & Ride-Sharing Portal

## Project Overview
The Campus Carpool & Ride-Sharing Portal is a Python-based application designed to help university students share rides to and from campus.

Students can register, log in, offer rides, search for available rides, book seats, view their bookings, and cancel bookings.

## Features
- Student registration and login
- Secure password hashing
- Add and offer rides
- Search available rides
- Book available seats
- View personal bookings
- Cancel bookings
- Generate reports
- CSV-based data storage

## Technologies Used
- Python
- Jupyter Notebook
- CSV (Comma-Separated Values)

## Project Files
- `Campus_Carpool_Ride_Sharing_Portal.ipynb` – Main application notebook
- `users.csv` – Student account records
- `rides.csv` – Ride information
- `bookings.csv` – Booking information
- `Campus_Carpool_Ride_Sharing_Portal_Report.docx` – Project report
- `Campus_Carpool_Ride_Sharing_Portal_Report.pdf` – PDF report

## How to Run
1. Install Anaconda.
2. Open Jupyter Notebook.
3. Open `Campus_Carpool_Ride_Sharing_Portal.ipynb`.
4. Run the notebook cells in order.
5. Follow the menu instructions.

## Data Storage
The application uses CSV files to store student accounts, ride details, and booking records. Data is saved so that it remains available after the program closes.

## Project Purpose
This project demonstrates Python programming concepts including functions, loops, file handling, CSV storage, and exception handling.
